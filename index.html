Market playbook

按「目标市场」逐个给：去哪找客户、用什么触达、有什么坑。不同市场差别很大——有的有提单级海关数据，有的（欧盟、日韩）法律上就查不到。 下面提到的第三方服务与其价格随时会变，请以各自官网为准；觅客舵不与任何一家有关联。

Search queries

搜索式（要你自己去搜）

这些不是已经找到的客户。它们是本地按你的产品和市场拼出来的 Google / LinkedIn 搜索语句——不联网、不花钱，所以永远有这么多条。 用法是：点「打开」在浏览器里搜 → 把结果里的公司官网复制下来 → 回到上面的输入框 粘贴导入，那一步才会真的产生线索。
想让软件替你搜、直接出公司列表，走的是另一条路：「联网找客户」/「一键起量」， 那条需要配好能联网的 AI（目前只有 Claude 支持），并且会按次消耗你的 API 额度。

Customs database

本地提单库 · 按供应商反查

导入的海关 CSV 会把原始提单存进本机（不上传、不进备份 JSON）。攒下来之后就能反过来查： 输入竞争对手的名字，列出所有从它进货的买家——这是提单数据独有的能力，竞品官网上的经销商页是宣传，这里是交易记录。 数据只在本机查询，不提供整库导出（多数数据商的条款允许订阅者自用、禁止再分发）。

Mail

收发信（直连模式）

填你的企业邮箱参数，应用直接收发，不用自建 n8n。密码用系统加密存在本机， 既不进界面也不进备份 JSON——导出备份发给客服不会泄露。
⚠️ 密码栏要填企业邮箱后台生成的客户端授权码，不是你登录网页版的那个密码。这是配置失败最常见的原因。

Data sources

找客户与补邮箱（直连）

和 AI 引擎一样，填个 API Key 就能用，不用经 n8n 中转。留空则回落到对应的 Webhook。 两家都有免费额度，具体额度与价格以各自官网为准。

这两家按次计费，而自动驾驶与周期补量会在后台静默调用——加个每日上限， 免得开着后台常驻睡一觉醒来额度烧光。到顶只是暂停调用，不影响其它功能，次日自动重置。

Dispatch

Webhook 派发

Webhook 模式下，把已批准且到期的邮件交给发信服务、已审批且到期的 WhatsApp 交给 Business API、潜客同步到 CRM。本地模式下此按钮仅做本地模拟发送。

Background

后台运行

自动驾驶跑在应用里，关掉应用就停。开启后台常驻后，关闭窗口只是收进托盘，自动驾驶继续工作； 要彻底停止请在托盘图标右键选「完全退出」。
需要 7×24 真正无人值守（比如关机也要跑），得把采集/发送放到 n8n + 外部 cron，见「n8n自建说明」。

Data safety

数据与备份

所有数据（线索/队列/黑名单/配置/API Key）只存在本机浏览器里：清浏览器缓存、换浏览器、换端口访问都会看不到数据。建议每周备份一份 JSON；换电脑时用备份文件恢复。
