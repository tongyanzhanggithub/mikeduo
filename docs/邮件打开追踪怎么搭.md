# 邮件打开追踪怎么搭

> 十分钟，免费额度足够用。搭完你能看到「谁打开了、打开了几次」，
> 而这些数据**不经过我们**——像素挂在你自己的域名上。

## 为什么要自己搭

别家软件的追踪像素挂在**他们的**服务器上。这意味着你所有客户的打开时间、
IP、设备型号，都先经过服务商再给你。

我们不做这件事，也没法替你做——软件是买断的、跑在你自己的电脑上，
我们没有服务器可以接收像素请求。所以这一段需要你自己搭一个极小的端点。

**不搭也能用**，只是没有打开数据。软件会在界面上明确标注「测不到，不是没打开」，
不会拿一个「预估打开率」糊弄你。

---

## 一、选一个（二选一，都有免费额度）

### Cloudflare Worker（推荐）

免费额度每天 10 万次请求，对个人外贸来说用不完。

1. 到 [cloudflare.com](https://cloudflare.com) 注册
2. **Workers & Pages → Create → Worker**，把
   [`docs/tracking/cloudflare-worker.js`](tracking/cloudflare-worker.js) 整个粘进去 → Deploy
3. **Settings → Variables → KV Namespace Bindings**：新建一个命名空间，变量名填 `OPENS`
4. **Settings → Variables**：加一个环境变量 `TOKEN`，值自己设一串长密码
5. **Settings → Domains & Routes**：绑一个你自己的子域名，例如 `track.你的域名.com`

### Vercel

1. 新建一个空 Node 项目，把
   [`docs/tracking/vercel-api-track.js`](tracking/vercel-api-track.js) 放到 `api/track.js`
2. [vercel.com](https://vercel.com) 导入该仓库 → **Storage → Create KV** → 连到这个项目
3. **Settings → Environment Variables** 加 `TOKEN`
4. Deploy，然后同样建议绑一个自己的子域名

---

## 二、填进软件

**设置 → 邮件打开追踪 → 追踪端点 URL**：

```
https://track.你的域名.com/t.gif?k=你设的TOKEN
```

**设置 → 数据源 → 发送状态回传 Webhook**：

```
https://track.你的域名.com/events?k=你设的TOKEN
```

第一个是往邮件里插像素用的，第二个是软件来取数据用的。两个都填才完整。

---

## 三、一定要用自己的域名

用 `xxx.workers.dev` 这类平台默认域名也能跑，但**建议绑你自己的子域名**，
最好和发信域名同一个根域（发信 `you@abc.com`，像素放 `track.abc.com`）。

理由：收件方的反垃圾系统会看邮件里的外链指向哪儿。指向一个和发件人毫无关系的
平台域名，是很典型的垃圾邮件特征；指向发件人自己的域名则正常得多。

---

## 四、验证它真的通了

搭完之后，浏览器直接打开：

```
https://track.你的域名.com/t.gif?e=test123
```

应该看到一个 1×1 的透明图（页面基本是空白的，这就对了）。然后打开：

```
https://track.你的域名.com/events?k=你设的TOKEN
```

应该看到 `{"events":[{"id":"test123","event":"opened",...}]}`。

两个都对，就说明通了。回到软件里发一封给自己，打开它，几分钟后拉一次状态，
潜客列表上应该出现「打开 1 次」。

---

## 五、几个要知道的事

**打开率天然不准。** Gmail、Outlook 等会预取图片（不管用户看没看），
而很多客户端默认屏蔽图片（真看了也不记）。所以：

- 打开数**偏高**的部分来自自动预取
- 打开数**偏低**的部分来自图片被屏蔽

**它适合看趋势和排序，不适合当精确指标。** 软件里用它做的唯一一件事，
是把「打开 ≥3 次却没回复」的线索排到前面——这个用法对误差不敏感。

**不追踪也不影响主流程。** 未配置时跟进按固定节奏走，界面会标注
「测不到，不是没打开」，不会因为缺数据就把人误判成「没兴趣」。

**隐私。** 像素 URL 里只带一个本机生成的不透明 id（形如 `o-x7f2k9`），
**不带收件人邮箱**——邮件源码是收件人可见的，把邮箱写进 URL 等于泄漏。
数据存在你自己的 KV 里，我们碰不到。

**欧盟/英国客户。** 在这些法域，邮件打开追踪属于需要告知的处理行为。
软件已经对欧盟市场强制注入退订说明，但**追踪本身是否要在隐私政策里声明，
请你自行确认**——这块我们只提供工具，合规责任在使用者。
