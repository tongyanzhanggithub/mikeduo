## n8n 四个工作流的口径

每个模板用户要改的参数不超过 5 个，Respond to Webhook 节点预开 CORS
（`Access-Control-Allow-Origin: *`），需要用户判断的分支都预设好默认值。

| 模板 | 对接 | 用户要填 | 对应软件设置项 |
|---|---|---|---|
| ① 找客户 | SerpAPI（免费 100 次/月） | API Key ×1 | 搜索采集 Webhook |
| ② 补邮箱+验证 | Hunter（免费 25 次/月） | API Key ×1 | 邮箱查找/验证 Webhook |
| ③ 发信 | 企业邮箱 SMTP | 主机/端口/账号/**客户端授权码** ×4 | 发信 Webhook |
| ④ 收回信 | 企业邮箱 IMAP | 主机/端口/账号/**客户端授权码** ×4 | 拉取回复 Webhook |

> ③④ 手册必须重点标：填的是**客户端授权码**不是登录密码——这是 90% 配置失败的原因。
